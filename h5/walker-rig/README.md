# 中间人物：真实二维骨骼绑定预览

本地入口：<http://127.0.0.1:8765/h5/walker-rig/>

本目录只涉及中间散步人物。`original.png` 是用户资源36原文件的直接副本，没有生成新人物，也没有拆开原图再拼接。

`rig-core.js` 包含7个骨骼节点：身体根节点，以及左右两条独立的髋→膝→踝链。子关节按父骨骼变换计算，绑定位置固定。原画使用连续三角网格与归一化骨骼权重进行线性蒙皮；`preview.js` 用 WebGL 绘制实时变形后的原始贴图。

页面提供播放、暂停、时间轴、幅度、周期、原始姿势、骨骼显示、海报方向，以及六个单关节的手动角度检查。当前默认幅度65%，周期3.2秒。

验证了128个动作时刻的关节长度恒定、权重和为1，以及所有网格三角形不翻转。数值记录见`rig-qc.json`。另检查了每个手动关节±6度的极值，没有三角形翻转。

## 当前能力边界

这是已实现的骨骼绑定与小幅动作检查版，并非已经完成的自然散步循环。单张原图中前后腿遮挡和鞋底透视已固定在纹理内，当前连续网格不会生成隐藏的腿部，也不会自动产生另一侧鞋面。要完成真实交替迈步，还需分层补全被遮挡的腿部、处理前后遮挡次序和鞋部透视。

H5主页面尚未接入这个检查版，其他六个人物没有在此次骨骼工作中修改。

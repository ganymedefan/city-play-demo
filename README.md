# 城市纯玩计划

完整静态 H5 项目，包含首页长图、人物动画、照片切换、贴纸人格测试和高清静态 JPG。

- `index.html`：入口，自动进入 `h5/index.html`。
- `h5/index.html`：1080 × 5760 设计尺寸的响应式长页面。
- `h5/assets/`、`h5/rig-motion.js`：首页图片和完整人物动画素材。
- `test.html`：点击开测后的贴纸选择、Loading 和人格结果卡流程。
- `visual/`、`assets/`、`people/`、`vendor/`：测试流程素材及第三方引擎；许可文件保留在 `vendor/`。
- `exports/城市纯玩计划-完整高清静态图.jpg`：2160 × 11520 完整静态图。
- `exports/file-manifest.json`：本次完整版本的文件清单、大小和校验值。

直接打开 `index.html` 可预览。也可在本目录启动任意静态文件服务器；项目无需 Node、安装依赖或构建步骤，可直接部署到 GitHub Pages。

当前首页保留完整人物帧动画和原图的纹理、照片与头像的相对位置；开测按钮随屏幕停靠，落到设计位置后停止跟随。蓝色 PNG 箭头在按钮停靠后绘制，完成后整体轻抖，离开再返回时重新绘制。底部小红书搜索图使用原始透明 PNG，按最终确认的位置居中摆放。

系统开启减少动态效果时，人物和装饰动效显示为静态版本。
